# ClipNova AI

Générateur de courtes vidéos à partir d'un texte avec Wan 2.1 T2V 1.3B.

Le premier démarrage télécharge un gros modèle et peut prendre plusieurs minutes. Les générations utilisent un GPU partagé ZeroGPU lorsqu'il est disponible ; les quotas gratuits, la file d'attente et les temps de génération sont limités. La disponibilité n'est pas garantie.
